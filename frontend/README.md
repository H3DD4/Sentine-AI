# Sentinel.AI — Red Team Workspace

Internal AI-assisted validation and reporting workspace for Forvis Mazars offensive security engagements.

## Features

- **Federated knowledge base** (NVD, MITRE, OWASP)
- **LLM-validated findings** with source provenance
- **Deterministic DOCX report generation**


## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
